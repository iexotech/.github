# Contributing to IEXO repositories

1. Read the repo's README. Ask for access if you don't have it.
2. Branch from `main`: `feat/…`, `fix/…` or `chore/…`. Keep branches short-lived.
3. Commit messages are imperative and describe the change.
4. Open a pull request. The repo's checks must pass.
5. Never commit secrets, real personal data, contracts or confidential material.
6. Contributions are accepted only from people with a signed contributor or engagement agreement.
