# .github (organisation defaults)

GitHub uses this repo's files as **defaults for every repo in the IEXO organisation** that doesn't have its own: contributing guide, security policy, PR and issue templates. `profile/README.md` is the public organisation profile.

⚠️ This repo becomes **public** when pushed, so it holds no confidential content. Profile text must follow the honesty rules: no claims of incorporation, customers or partners until they're true and approved.
